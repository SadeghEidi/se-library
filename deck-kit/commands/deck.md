---
description: Build, review or rebuild a pitch deck with the deck kit.
---

Use the `building-a-pitch-deck` skill for this. It is bundled with this plugin
and carries the whole procedure: which narrative spine fits the room, the slide
craft rules, the visual system, and the checklist to run before anything is
sent.

The tool is `${CLAUDE_PLUGIN_ROOT}/bin/deck.sh`. Decks land in `./decks/` in
whatever project is open.

$ARGUMENTS

If nothing was asked for specifically, start where the skill says to start:
work out which room the deck is for, then write the action titles as a list and
get them agreed before building a single slide.
